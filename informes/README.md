# Informes de búsqueda diaria

La rutina en la nube "Búsqueda de empleo diaria — Saúl" deja aquí un archivo
`AAAA-MM-DD.md` cada mañana laborable con las ofertas nuevas que encajan con el perfil
(criterios en `../daily_search_profile.md`).

Para recibirlos por email: activar **Watch → All Activity** en el repo en GitHub;
GitHub envía un correo por cada commit nuevo.
